# Roadmap

## MVP 범위

**포함**
- 회원가입 / 로그인 (JWT)
- 문제 목록 / 상세 (지문, 입출력 예시, 시간·메모리 제한)
- 코드 제출: C++, Python, Java
- 비동기 채점 및 결과 확인 (AC, WA, TLE, MLE, RE, CE)
- 내 제출 기록

**MVP 이후**
- 관리자 문제 등록 화면, 테스트케이스 업로드
- Python 기반 테스트케이스 자동 생성기
- AI 힌트 / 코드 리뷰
- 랭킹, 대회 모드

## 주차별 일정

| 주차 | 목표 | 완료 기준 |
|---|---|---|
| 1 | 레포 구조, Sandbox Runner v0.1 | 5가지 판정 테스트 통과 |
| 2 | Judge Worker | 큐에 넣은 제출이 자동 채점되어 결과 JSON 생성 |
| 3 | API 도메인 (회원, 문제, 제출) | Postman으로 제출 → 결과 조회까지 동작 |
| 4 | Frontend | 브라우저에서 문제 풀이 → 결과 확인 |
| 5 | 격리 강화 (Docker, seccomp) | 파일 삭제·네트워크 접근 코드가 차단됨 |
| 6 | 배포, 부하 테스트 | 공개 URL, 동시 제출 처리량 수치 README에 기록 |
